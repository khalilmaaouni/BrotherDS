4. The pilot estate's gold DuckDB file (claimed 84 tables, 86/86 verifications) does not exist at its recorded path -> a "verified" build artifact is only evidence until the file is deleted or moved; re-check paths with `ls`, never trust a path from memory or an old note (data-lakehouse-doctrine.md "never-rebuild law" exists specifically because the main warehouse file vanished once already).
5. A declared 7.41M-token spend ceiling never fired: numerator field always null, the real brake code never executed once across a whole transcript, the shown meter summed only output tokens while cache-read ran 295x larger, and the off-switch had no expiry -> a limit not measured from OUTSIDE the thing it limits does not exist; check the stop is actually wired before trusting a ceiling (a-ceiling-nothing-computes-is-not-a-ceiling.md, quantified).
6. A ChatGPT API "total" field looked like a count but was `limit+1` (a has-more flag); pagination stopped after 200 of 3,950 items with exit code 0, and a small-probe misread produced a false claim to the founder that his history had been restricted to 6 conversations -> never trust a field because its name is convincing; vary an input and watch the field before it controls a loop or becomes a claim to a human (pagination-total-that-is-not-a-count.md, live-probed).
7. A reviewing subagent's vivid, operationally-detailed exploit report reached the founder as headline news in under an hour with zero reproductions; it never reproduced in six later attempts -> alarming findings need MORE reproduction, not less; a claim's operational detail and the model's seniority are not evidence (a-measured-sounding-claim-is-not-a-measurement.md).
8. A hand-written private-name sweep compared case-sensitively and reported clean while the shipped control (which normalizes case) found hits -> a verification you author is a hypothesis; the shipped control is the arbiter, run it after the last edit and quote it (the-sweep-you-wrote-is-not-the-control.md).
9. A private-name control was RED for a day, dismissed as "environmental" by two sessions -> pre-existing and environmental are different claims; name what would make a red check green before dismissing it (a-red-control-read-as-environmental.md, per index).
10. Two published documents credited a hook for a refusal that was measurably never running (grep found zero registrations) -> a control you observed working may be a different product's; measure which control actually fired (crediting-a-control-that-was-never-running, 2026-08-15).

12. A figure true in one directory/tree was reported as generally true (5+ instances one session, 8 total that night) -> a measurement without its tree and revision stated beside it is not a measurement (a-number-true-in-one-directory-reported-as-true-generally.md).
13. A full test battery reported FAIL on a suite that then passed 53/53 minutes later, the tree had changed under the run twice from a concurrent session -> commit, confirm clean, confirm HEAD hasn't moved, then measure (a-suite-measured-on-a-moving-tree).
14. A reviewer's summary named the wrong file as the hole; reproducing first showed the real defect was one file upstream -> reproduce before fixing even when a trusted reviewer names the file (a-finding-filed-from-a-summary-names-the-wrong-file).

24. Six local test suites were green; CI was red on all five legs because a generated section had not been regenerated -> extract every CI command with a parser and run the full battery locally before pushing, not a subset (a-local-sweep-narrower-than-the-ci-battery.md).
25. A pinned CLI invocation, verified once, rotted as the underlying CLI grew a new required flag; five funded baseline runs died on it -> re-verify flag combos against the installed `--help` before any unattended or funded run (a-pinned-invocation-rots-as-the-cli-updates.md).
